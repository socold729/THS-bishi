记录约定：

- “文档声明”“在线目录已列出”“真实取数成功”分开记录。HTTP 200、MCP 初始化成功或能列出工具均不代表取数成功。
- 原始请求证据时间使用 UTC；面向用户的阶段日期使用 America/New_York；金融数据时区以供应商字段说明为准。
- 新记录追加日期、执行者、输入、实际结果、证据位置和遗留问题；未执行的步骤必须写“未执行/待验证”。
- 不写入密钥、Cookie、用户隐私、真实持仓或受限金融数据。未来保存响应前先核实授权并脱敏。
- 本目录不替代最终产品 README 或测试报告；最终交付须随实际实现和验证更新。
