## 扶摇

官方来源：[接口总览](https://fuyao.aicubes.cn/docs/api-reference/overview/)、[快速开始](https://fuyao.aicubes.cn/docs/quickstart/)、[MCP 概览](https://fuyao.aicubes.cn/docs/mcp/overview/)、[完整文档](https://fuyao.aicubes.cn/llms-full.txt)。

### 核心数据与接口

所有下列路径以 `https://fuyao.aicubes.cn` 为前缀，REST 查询使用 GET。完整名称映射见 [官方工具目录](官方工具目录.md)。

| 数据类型 | 代表接口 | 关键边界 |
|---|---|---|
| 标的检索与代码表 | `/api/meta/tickers/search`、`/list` | 名称/代码消歧及跨市场标的元信息，不代表所有市场行情可用 |
| A 股快照 | `/api/a-share/prices/snapshot` | `thscodes` 批量或省略后分页；批量模式忽略分页参数 |
| A 股历史日 K | `/api/a-share/prices/historical` | 单标的；毫秒起止时间；只支持 `1d`；一次窗口不超过 10 年；支持不复权/前复权/后复权 |
| 复权事件 | `/api/a-share/corporate-actions/adjustment-factors` | 原始分红、送股、配股事件；使用时须核对复权口径 |
| 指数/板块与成分 | `/api/a-share-index/catalog/ths-index-list`、`/constituents/ths-stock-list` | 同花顺行业/概念等目录；当前成分，也支持标准指数；不能据此假设历史成分可用 |
| 指数快照与历史日 K | `/api/a-share-index/prices/snapshot`、`/historical` | 历史接口单指数、日线，查询区间须在近 5 年内 |
| 最新估值 | `/api/a-share/valuations/snapshot` | PE TTM/MRQ、PB MRQ、PS TTM、PCF TTM；默认最多 100 个原始代码 token；不提供历史估值、分页、指标选择或高低估结论 |
| 财务三表 | `/api/a-share/financials/income-statements`、`/balance-sheets`、`/cash-flow-statements` | 单公司合并报表；年/季报；最近 1–20 期或不超过 10 年的区间，两模式互斥；金额原币元、EPS 元/股；null 不等于 0 |
| 财务指标 | `/api/a-share/financials/indicators` | 成长、盈利、偿债、营运、现金流等分类；以具体指标和报告期为准 |
| 交易日历 | `/api/a-share/calendar/trading-days` | 无参数，固定近一年至今日；不能作为任意历史/未来日历接口 |
| 特色数据 | `/api/a-share/special-data/*` | 涨停/跌停/炸板池、连板天梯、热股/飙升榜、历史热榜、排名走势、异动原因、龙虎榜；各接口分页/日期范围不同 |
| 集合竞价、新股 | `/api/a-share/auction/*`、`/api/a-share/ipo/calendar-list` | 快照、基准和申购日历；扩展机会筛选等文档条目须单独验证 |
| 基金 | `/api/fund/*` | 基本资料、基金经理/公司、净值/收益、配置/持仓、财务、诊断、募集/资讯、场内行情、回测、QDII 额度；报告期持仓不等于实时持仓 |
| 期货/期权 | `/api/futures/*`、`/api/options/*` | 品种/合约、行情、时间轴；期货还含持仓、仓单、基差等；端外分时仅当前交易日、K 线仅日 K |
| 港股新股 | `/api/hk-share/ipo/*` | 递表、认购/待上市、发行详情；不是港美股通用行情承诺 |
| 公开资讯查询 | `/api/news/article/detail`、`/flash/list`、`/notice/detail`、`/topic/hot-list` 等 | 当前具体 REST 文档列为公开能力；原文、可检索范围与权限仍需实测，不能与客户端专属事件库混同 |

上述限制依据对应 [价格](https://fuyao.aicubes.cn/docs/api-reference/prices/)、[指数](https://fuyao.aicubes.cn/docs/api-reference/a-share-index/)、[估值](https://fuyao.aicubes.cn/docs/api-reference/valuations/)、[财务](https://fuyao.aicubes.cn/docs/api-reference/financials/)、[日历](https://fuyao.aicubes.cn/docs/api-reference/calendar/) 及完整文档。

### 认证与服务入口

- 同花顺账号登录，在 [API Key 管理](https://fuyao.aicubes.cn/admin/) 签发 Key，并确认 capability 权限。
- REST 和托管 MCP 都使用 `X-api-key` 请求头；自托管 MCP 文档使用 `API_KEY` 环境变量；CLI/SDK 的统一变量为 `HITHINK_FINANCE_API_KEY`。本阶段未安装这些工具，也未创建 Key。
- MCP 按域分为 `/mcp/a-share`、`/mcp/a-share-index`、`/mcp/fund`、`/mcp/futures`、`/mcp/options`、`/mcp/hk-share`、`/mcp/meta`、`/mcp/news`。
- 文档通用响应为 `code/message/request_id/data`，业务错误常见 HTTP 200。必须同时检查 HTTP 状态和业务码，MCP 还需检查 JSON-RPC 错误与内层业务结果。
- 文档错误码：2001 未认证、2003 权限不足、4001 限流，另含参数错误、标的不存在、数据未就绪、内部/上游错误。本次缺少 Key 实际返回 2003，与文档分类不同。
- 当前文档称累计调用次数不限，但频率随负载动态限制；未给统一固定 QPS。HTTP 429 或业务 4001 均需按限流处理，不可解释为无限并发或永久免费承诺。
- 金融时间按 Asia/Shanghai、时间戳为毫秒；单位以字段定义为准，null/空列表需保留语义。

### 不应视为端外已可用的能力

主力资金、高频动向、宽基 ETF 申购净流入、筹码形态、市场成交额预测、新增概念、资讯事件库等页面注明客户端内能力；期货 F10 宏观数据也不作为端外入口。不能因为存在路径就写入可用清单。

文档存在范围表述差异：[开发工具概览](https://fuyao.aicubes.cn/docs/developer-tools/overview/) 对新闻公告原文、海外行情等的公开范围较保守，而当前 REST/MCP 总览已列出资讯、期货期权和港股新股条目。记录其差异，以具体端点、实际 schema 和授权返回为准，不替供应商推断统一可用范围。

本次 A 股 MCP 实际列出 21 个工具；文档映射中的另 8 个 A 股扩展工具未在该次无凭据目录中出现。不能推断它们彻底不存在、对应 REST 不可用或授权后仍不可见。

## iFinD MCP

官方来源：[题目入口](https://mcp.51ifind.com/?syncCookieTimes=1)、[前置准备](https://mcp.51ifind.com/#/documents/guide-prepare)、[综合服务](https://mcp.51ifind.com/#/documents/mcp/overview)、主页指定 [完整文档 CDN](https://s.thsi.cn/cd/ifind-java-ds-bff-web-container/ifind-mcp-web/llms-full.txt)。工具概览标注更新日期 2026-10-16；这是文档标注，不代表实测通过日期。

| 数据域 | 文档列出的工具示例 | 可支持方向及边界 |
|---|---|---|
| 综合服务 | `get_security_indicators`、`search_securities`、`security_highfreq_quotes` | 跨证券指标、筛选和当日行情；与细分服务工具组织不同 |
| A 股 | `get_stock_info`、`get_stock_performance`、`get_stock_financials`、`get_stock_shareholders`、`get_risk_indicators`、`get_stock_events`、`get_esg_data`、`stock_highfreq_quotes` | 基础信息、日行情、财务估值、股东、风险、事件、ESG、日内快照/分钟 |
| 指数/板块 | `index_data`、`sector_data`、`index_highfreq_quotes` | 指数行情/估值、市场/行业/概念板块和成分统计 |
| 宏观行业 | `search_edb`，细分 `get_edb_data`，综合 `fetch_edb` | 经济指标检索及时间序列；不同服务名称不能互换猜测 |
| 新闻公告 | `search_news`、`search_notice`、`search_trending_news` | 相关内容或片段、热点事件；并非承诺任意全文下载 |
| 基金 | `search_funds`、`get_fund_profile`、`get_fund_market_performance`、`get_fund_portfolio` 等 | 产品、净值/行情、持有人、披露组合、财务、管理人、当日行情 |
| 债券 | `bond_basic_info`、`bond_market_data`、`bond_financial_data`、`bond_special_data`、`bond_highfreq_quotes` | 资料、估值、发行人财务、评级/转债条款、日内行情 |
| 港美股 | `search_global_stocks`、`global_stock_profile`、`global_stock_quotes`、`global_stock_financial`、`global_stock_events` | 公司、日行情、财务估值与公开事件；不能推断含实时海外行情 |
| 期货期权 | `future_profile`、`future_quotes` | 合约、日行情、成交持仓 |
| 其他独立服务 | 快查、法智 | 企业资料和法律信息；额外工具权益限制，不是本题必用能力 |

题目点名的“市场宽度、资金、政策”在已读工具概览中没有一一对应的专用工具与完整字段契约。`sector_data`、证券指标、新闻/法规检索是候选入口；是否含涨跌家数、资金净流入、政策原文等，须取得授权 schema 并实际查询。自行由成分行情计算市场宽度也只是未来可能方案，当前未设计或实施。

### 认证与传输

- 使用同花顺 APP 或 iFinD 账号登录开通；个人中心查看用量，获取 MCP 密钥，按服务“生成配置”。
- 官方公开参考包的配置字段是 `auth_token`，请求头直接设置 `Authorization: <MCP密钥>`，示例未添加 `Bearer`；应遵循用户账号生成配置，不能自行套用 Bearer 或复用扶摇 Key。
- 本次仅只读查看参考包 `call.py`/`call-node.js`/配置模板，没有安装、执行脚本或导入该 Skill。
- 参考包服务基址：`https://api-mcp.51ifind.com:8643/ds-mcp-servers`。A 股后缀 `hexin-ifind-ds-stock-mcp`；其他域包括 `hexin-ifind-ds-{fund,edb,news,bond,index,futures}-mcp` 和 `hexin-ifind-ds-global-stock-mcp`。账号生成配置为后续接入依据，不能据包内地址断言当前账号均已开通。
- 示例使用 HTTP POST、JSON-RPC，`Accept: application/json, text/event-stream`，初始化协议版本 `2025-03-26`，后续使用 `Mcp-Session-Id`；需先初始化、通知、`tools/list` 获取实际参数，再 `tools/call`。
- 本次 A 股初始化 HTTP 401，未取得工具列表、参数 schema、会话或金融数据。
