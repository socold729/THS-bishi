## 目前产品实际使用什么

- `src/lib/finance/server.ts` 和 `dashboard.ts` 使用扶摇 **REST** 取数。它们没有通过 MCP 调用金融工具。
- iFinD Skill 安装在 Codex 用户目录，本次是在开发助手中调用；Web 应用没有 iFinD MCP 客户端或新闻/公告证据适配层。
- `IFIND_ENABLED` / `IFIND_MCP_KEY` 目前只是模板预留变量，应用源码没有读取并接入。不能只把开关改成true就宣称接入成功。
- 当前图表从截止所选日的**日线**聚合周/月K，不直接使用此次发现问题的原生MCP周线。新闻和公告也没有进入正式AI分析，因此本次发现的越界新闻未被注入产品报告。

## 仍然缺少什么

1. iFinD指数服务稳定初始化与真实指数/板块业务取数。
2. 新闻服务端日期边界的可靠性核验；接入前必须逐条按报告日过滤，越界或无日期内容不送模型。
3. 公告原文链接和原文核验；片段不能冒充完整公告，更不能直接取代财报数值。
4. 原生周K截止边界、指数周K5003的供应商核查；本轮未测原生月K，不能将其说成失败或成功。
5. Web端iFinD适配、不同供应商成功码归一化、来源/时间/单位/口径检查及正式报告接入。
6. 全市场宽度、资金流、行业轮动的完整链路。它们仍是未验证/未实现，不能只因某个目录有工具就认定可用。
