# 价值复盘增量实现｜2026-10-28

保留原MVP记录。本轮补齐可开发部分，外部接口连接状态与产品实现状态分别验收；没有部署公网。

## 数据流

`日期/自选 → 六类已披露三表 → 期末/披露/币种对齐 → 程序指标 → 可选iFinD历史估值/公告 → 原子证据 → OpenAI结构化报告 → 服务端校验 → 展示`

年度、季度各请求利润/资产负债/现金流16期，优先取得全部自选的财务基础，再请求可选MCP。年度与季度展示最新两期；同比基准是上一年相同报告期，季度不计算环比。比值仅在相同期末、已知同币种、有效分母下计算；同比币种必须一致。`total_debt`按供应商文档解释为负债合计，不能改称有息债务。

财务字段、期末、披露日和计算口径进入证据。多表指标的来源弹窗展示全部相关表；报告每条原子证据包含唯一ID、实际披露日、金融字段、单位和来源。已披露旧财报不称作所选日新公告。供应商修订历史版本不能完整还原，保留限制。

## iFinD适配与边界

服务端只访问官方HTTPS端点，执行initialize、initialized通知、tools/list、tools/call；凭据来自环境变量，不读用户技能目录、不改官方Skill。请求串行，复用短期会话；同时检查HTTP、协议、工具与内层code=1/msg=success，不把连接/HTTP成功等同取数成功。网络失败不自动重试。

Node HTTPS传输参照已安装官方Node库的方式，避免原生fetch自带连接时限提前到期。该调整不保证外部服务可用；本轮真实连接仍有初始化超时/重置，未编造权限不足原因。

- 公告：最多3条相关片段，逐条校验日期区间及标题公司身份，排除未来/错公司/缺日期。返回URL须为无嵌入认证的HTTP(S)地址；返回链接不表示程序已读全文。缺URL明确显示，片段不代表完整公告目录；无结果不能断言没有新变化。只把限定前120字输入AI，明确为片段。
- 历史估值：请求所选日及少量明确半年度时点；仅接受准确代码、准确请求日期、可解析数值和明确PE(TTM)/PB字段。冲突时点整体排除，最新快照不能填历史。少量样本不计算分位或判断贵便宜。适配/Mock通过不等于真实历史取数成功。

## 投资假设

用户自己填写文字和数值条件，可选年度/季报营收同比、年度/季报资产负债率、年度经营现金/净利润。程序以服务端重取的当期指标判为“指标符合条件/触发复核/证据不足”，不是判断整套投资逻辑成立，不给交易建议。

记录保存在当前浏览器`mingri.value-hypotheses.v1`，含创建时间、开始回看日期、历史版本与逐日核验。修改产生新ID并归档旧版本，同日同值去重，修订值另记；可导出JSON。记录是现在回看历史，不冒充用户当时的预测。仅按实际访问的数据追加，不是后台每天自动运行。无账号与跨设备同步；损坏存储不覆盖、保存失败不清空输入。最多10条活动、100版本、5000核验；超限提示不删旧数据。

模型不读取私密假设文字。请求只传枚举指标与自设阈值；这些条件与真实金融事实分开标明，模型只接收服务端生成的规则结果。条件变更参与任务配置键，原报告立即失效。
