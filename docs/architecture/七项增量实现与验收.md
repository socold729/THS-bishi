# 明日游资七项增量实现｜2026-10-28

本轮沿用当前Next.js项目、三种固定投资风格、真实数据层与原记录。没有初始化新项目、创建账号、部署公网或将密钥放进前端。

## 功能与数据结构

| 修改 | 实现与边界 |
|---|---|
| 主动保存报告 | 生成后点击“保存到复盘档案”；本地版本追加、同一生成结果幂等、保存失败不显示已保存；档案按日期/风格筛选、查看全文和证据，刷新保留 |

| 去除指数播报 | 模型指令明确禁止行情播报，服务端拒绝只有指数收盘/涨跌的事实项；允许相关推断按对象引用后台指数证据；不靠前端隐藏 |

### 复盘档案

本地键`mingri.report-archive.v1`，结构为`{version:1,entries:[ArchivedReport]}`。每条包含独立UUID、同日期/风格下版本号、保存时间、配置快照、当时偏好快照、完整ReviewReport。报告含日期/风格/生成时间、实际响应模型名、responseId、事实/推断/不确定性、全部原子证据及来源和口径。保存时深复制，不与当前配置对象共用引用。

只接受用户主动保存；没有自动归档。最多100份，超限提示不删旧报告。读取坏数据不覆盖，配额/存储失败明确提示。支持跨标签页刷新；具备Web Locks时串行写入，降低标签页并发覆盖风险。仅存当前浏览器，不跨设备同步，清理浏览器数据会丢失；没有云数据库。

### 自定义AI工作流

`当前风格+已保存要求 → 有限范围规划 → 服务端Schema/风格白名单/标签安全检查 → 按scopes选择真实取数 → 程序指标/完整性检查 → 动态报告Schema → 引用/数值/对象/日期/合规校验 → 保守去重 → 显示 → 用户选择归档`

ReviewPlan仅可选择白名单数据范围、最多3个明确行业、1至5个自定义栏目及是否显示自选；不能提供执行代码、任意URL、额外证券类型或第四种风格。解析失败明确失败，不退回完整默认报告。请求接口不接收浏览器金融数据或浏览器自定工具计划。分析输入中的偏好和金融文本都属低信任数据，不能改变服务端规则。

默认模式不调用规划模型，保留各风格数据逻辑并应用本轮要求的指数/波段/价值改进。配置键含用户要求和假设条件；更换后旧任务取消、旧结果不发布。ReportConfiguration快照含style、symbols、customInstructions、hypotheses、实际ReviewPlan，写入新报告；历史档案不重算、不重新取数、不调用模型。

任务总预算135秒，规划最多20秒，报告模型默认45秒；数据层保留按策略的取数预算。API运行时nodejs，密钥仍只读环境变量。开发服务/构建/浏览器回归顺序执行，未新增大型备份。

生成Schema还将当前分析对象限定为枚举、自选列表限定为精确数量/代码，并以嵌套anyOf区分fact/inference/uncertainty：事实叙述必须为空、事实与推断必须绑定数据、推断/不确定性叙述必须带显式标识。服务端仍独立核对全部引用和值，不把Schema通过当作事实通过。报告可由已核对事实，或带逐值核对引用数据的明确推断构成；引用数值单独标为“字段已核对”，推断文字仍待验证。只有无数据不确定性的报告不发布。

该生成格式依据实际阅读的[OpenAI官方Structured Outputs文档](https://developers.openai.com/api/docs/guides/structured-outputs)：根为对象、嵌套anyOf与pattern约束；本轮保留用户配置型号，不自动切换模型。真实首次失败、诊断、原文回放和新生成分别记录，回放不计新模型调用。

### 财务环比核验

扶摇文档明确字段是合并报表和每个季度末，但未明确单季/累计。不能仅凭period=quarterly判定单季，也不能因数值递增猜累计。本轮取到归母字段parent_holder_net_profit，程序分别对营收与归母净利润核验。

每个当前/前季必须匹配证券代码、报告期末、iFinD“单季度”列及合并报表/实际季度元数据。累计字段与扶摇值、单季字段与累计差分均须吻合；误差按每个单元格实际量级与小数位计算，过粗显示不用于确认。没有一律放宽5000元；四位小数的“亿”显示最多约5000元舍入。最初一次响应单季季度参数与日期矛盾，已排除；后续针对明确季度的请求才通过交叉核对。

Q1单季=本年Q1累计；Q2/Q3/Q4单季=同年本期累计−上期累计。Q1对上年Q4时，上年Q4单季=年度累计−前三季度累计。输入按所选日披露/期末过滤且币种一致。变化额=本季单季−前季单季；变化率=(本季单季/前季单季−1)×100，仅前季>0。零/负前季仍可显示变化额，变化率留空；缺期/口径不明/元数据不符/未来披露均显示“暂无可比环比数据”。不保证供应商历史修订版本还原。

### 行业发展证据

公司行业/业务使用iFinD资料，必须有对应证券代码及等于所选日的截止日期元数据。行业级别尾缀规范化后精确匹配扶摇目录；不能以相似名称替代。目录仅定位代码，不表示已还原历史成分。行业日线聚合周/月趋势和量能，行情不足或已知交易日有缺口时停算；周期未结束及早期预热日历边界明确标注。

资讯限相关行业、近30天、最多3条，过滤未来日期、错行业和无HTTP(S)链接。它们是返回片段，不是已核验全文、全部政策目录或景气统计；没有片段/指标时不能从行业名或价格上涨编造发展。公司潜在影响的引用只关联到已核对同日行业归属的公司，事实与推断分别标记。完整政策文本与全面行业景气指标仍有能力边界。
