## 异动计算范围和约束

依据2026-07-06生效的[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)及[深交所2026规则原文](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf)，累计偏离用证券区间复合涨跌幅减对应指数区间涨跌幅，不能累加每日百分比。10个交易日内+100%、30个交易日内+200%是本轮覆盖的两种向上严重异常波动条件；没有覆盖全部异常交易类别、同向异动次数或换手率规则。

常规沪市主板基准000002.SH（上证A股），深市主板399107.SZ（深证A股），创业板399102.SZ（创业板综），科创板000688.SH（科创50）。这些是规则专用基准，不替换Dashboard中的科创综指000680.SH。指数身份依据官方交易规则、中证000002资料及国证399102资料/深交所399107公告；四条扶摇真实日线请求全部成功，各56条。

检查范围为自选股优先、再加入当日按连板排序涨停池，共最多30只，并非全市场。每个标的要求个股与基准对应最近31个交易日完整，ST/退市标识及不支持市场跳过。窗口内有已返回除权除息事件时不测算；未来行情不进计算。遍历含下一交易日的各个不超过10/30日区间，选取可在常规涨停限制内达到阈值的最低条件涨幅，价格向上取整至分币，区分两种类型。

**这是条件测算，尚不是完整的监管异动预警名单。** 默认假设下一交易日基准指数涨跌0%、普通限幅、没有新除权或规则重置。完整交易所公告重置记录、未来除权/风险状态变化尚未核验；这些条件始终在卡片可见。提醒不代表次日涨跌预测或监管认定。早于规则生效日、无法确认交易日、历史缺失或接口失败不生成伪造提醒；部分样本跳过不会表述为全市场没有异动。

扶摇真实monitor历史接口虽返回记录，但字段是监控区间，缺少可安全还原历史公告/规则重置的完整时点，未直接冒充重置数据。除权接口对明确无事件证券返回HTTP200/code3002/message为“No adjustment events for thscode=指定代码”；只在该端点、代码及证券消息精确匹配时转为明确空事件，其余业务错误仍失败。原失败探测和后续语义核对分别保存。

## 数据结构与文件

- 新增Metric族：volume/turnover-current、previous、daily-delta、five-day-average/delta、month-current/previous/delta；每个保留统计方法、所选日和来源ID。行业指标以industry-为前缀。
- AnomalyAlert：code/name、benchmark、window/threshold、lookback、requiredRise/referencePrice/currentPrice/deviation、evidenceIds、conditional=true。
- AnomalyData：date、status、alerts、candidateCount/checkedCount、scope/messages/evidence；新服务端GET /api/anomalies，短期去重缓存60秒。
